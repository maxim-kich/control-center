# Control Center v0.1.2

## Updates respect file ownership

- Updates and rollbacks now replace modified, deleted, renamed, and untracked image-owned application files automatically.
- User-owned extensions, projects, configuration, databases, uploads, and generated runtime state remain untouched.
- Update dry runs report the image-owned paths that will be replaced without changing them.
- Path validation prevents the updater from removing files outside the application checkout.

This fixes updates failing with `image-owned files are modified` when the installed application code differs from its release commit.
